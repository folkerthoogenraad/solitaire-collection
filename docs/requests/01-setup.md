## Documentation

Create `AGENTS.md` to describe the following:
 - `/docs/requests` contains user audited requests. An agent is explicitly instructed to implement these requests and should update or alter these files.
 - `/docs/feedback` contains user audited feedback. This is random, unstructured feedback on the app. This can be anything, like colors mismatching, layout issues, whatever. 

Agents sometimes are asked to created plans. These should be added in `/docs/plans/<plan>/PLAN.md`. The `<plan>` should match the name from the request. Not every request needs a plan, but sometimes they do. A user can instruct the agent to make designs and mockups for example, or other documents. This should be in plans.
