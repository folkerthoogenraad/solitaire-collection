  • A full 14-card row is 13 × 22 + 36 = 322 px, which fits in 366 px. The 11 rows take about 590 px.
  • Trade-off: unconventional for solitaire, since you drag along the rows instead of down columns. Desktop uses rows as well, so the two layouts stay the same game.
