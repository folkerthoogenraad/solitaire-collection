## Feedback on skinning

All the feedback in this chapter is about skinning. I want some alterations and additions to the way the skinning works.

The pips and indexes both need artwork for the suits. It is really good that we can seperate them, but we probably want to fallback to either if not specified. I.e. if the index doesn't contain the pips, we fall back to the pips in the pips folder. I want the user to be able to create a skin with as few things as possible to get started, and customize from there.

Keep `slot-stock[.ink].png`, but fall back to the normal slot.ink.png. Add a `stock[.ink].png` to customize the stock center image without also including the outline. That would be just the image of the word "stock".

The "Wins" needs to be a skinable asset (`ui/wins.png`)

The "New deal" needs to be a skinable asset (`ui/new-deal.png`). The new deal does not need a "are you sure" anymore. Just click the new deal and you get a new deal immediatly. Not sure whether this is permanent, but makes skinning easier.

The win counter needs to be made up of the index numbers. Add index numbers for `index/0.ink.png` and `index/1.ink.png` to make up for the fact that those are not in. The 10 should only be used on the cards, the win counter can just use 10 instead.
